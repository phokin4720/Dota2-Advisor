# Dota Advisor

ผู้ช่วย Dota 2 ระหว่างเล่น แสดงข้อมูลเกมแบบเรียลไทม์ แนะนำไอเท็มแก้ทางและชิ้นส่วนถัดไป พร้อมสถิติ matchup และสิ่งที่ควรระวังจากฮีโร่ศัตรู

## สิ่งที่ต้องมี

- Node.js 18.17 ขึ้นไป
- Yarn
- อินเทอร์เน็ตสำหรับโหลดข้อมูลฮีโร่และไอเท็มจาก OpenDota

## เริ่มใช้งาน

1. เปิด Terminal แล้วเข้าโฟลเดอร์โปรเจกต์:

   ```bash
   cd dota-advisor
   ```

2. ติดตั้ง dependencies:

   ```bash
   yarn install
   ```

3. คัดลอก `gamestate_integration_advisor.cfg` ไปไว้ในโฟลเดอร์นี้ภายใต้โฟลเดอร์ติดตั้ง Dota 2:

   ```text
   game/dota/cfg/gamestate_integration/
   ```

   หากยังไม่มีโฟลเดอร์ `gamestate_integration` ให้สร้างขึ้นก่อน

4. ใน Steam ไปที่ **Dota 2 > Properties > Launch Options** แล้วใส่:

   ```text
   -gamestateintegration
   ```

5. กลับมาที่ Terminal แล้วเริ่มแอป:

   ```bash
   yarn dev
   ```

6. เปิด [http://localhost:3000](http://localhost:3000) แล้วเข้าเกม Dota 2 เลือกฮีโร่ศัตรูบนหน้าเว็บเพื่อดูคำแนะนำ

## เปิดบนมือถือ

ให้คอมพิวเตอร์และมือถืออยู่ Wi-Fi เครือข่ายเดียวกัน จากนั้นเริ่มแอปด้วย:

```bash
yarn dev --hostname 0.0.0.0
```

เปิดเบราว์เซอร์บนมือถือไปที่ `http://<IP-ของคอมพิวเตอร์>:3000` โดยแทน `<IP-ของคอมพิวเตอร์>` ด้วย IP ภายในเครือข่ายของเครื่องที่รันแอป

## คำแนะนำไอเท็ม

- คำแนะนำแก้ทางใช้กฎจากบทบาทและประเภทการโจมตีของฮีโร่ศัตรู คะแนนเป็นค่าประเมิน ไม่ใช่อัตราชนะ
- ระบบแสดงชิ้นส่วนไอเท็มถัดไปจากของที่มีใน inventory
- ไอเท็มเพิ่มดาเมจอิงจากไอเท็มที่ผู้เล่นฮีโร่นั้นนิยมออก ไม่ได้ปรับตามศัตรู
- สถิติ matchup และคำเตือนเป็นข้อมูลประกอบ อาจไม่ตรงกับแพตช์ปัจจุบัน
- รายละเอียดไอเท็มอ้างอิง[โน้ตแพตช์ 7.42 ของ Valve](https://www.dota2.com/patches/7.42)
